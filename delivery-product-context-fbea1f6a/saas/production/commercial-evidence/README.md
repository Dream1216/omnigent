# Production commercial acceptance evidence

This directory intentionally contains no qualifying evidence. Only immutable,
exact-revision `production_commercial_acceptance` records derived from real provider,
payment, invoice, tax, ledger, and customer-acceptance workflows belong here.

Synthetic provider receipts, Stripe/test-mode transactions, local ledger fixtures, CI
reconciliation, screenshots, and a product owner's unilateral assertion do not qualify.
Identifiers must be SHA-256 values and the raw financial bundle must remain in the
restricted immutable artifact.
