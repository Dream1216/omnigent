# Production enterprise acceptance evidence

This directory intentionally contains no qualifying evidence. Only immutable,
exact-revision `production_enterprise_acceptance` records from real Staff and customer
IdPs, SCIM, MFA, audit, privacy, legal-hold, deletion, and Platform Console exercises
belong here.

Local mock IdPs, CI browser fixtures, SCIM protocol unit tests, screenshots, and
single-actor assertions do not qualify. Store only hashed identities and metrics here;
raw IdP, audit, and customer artifacts stay in the access-controlled immutable bundle.
